* **Высокие нагрузки:** оптимизация модуля сотрудников для баз **>100 000 пользователей**.
* **Интеграции и рефакторинг:** оптимизация тарифов (удаление лишних таблиц), синхронизация с CRM, работа с On-Premise и файловым хранилищем.
